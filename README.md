# CleanCity — Smart Waste Management System

**SDG 11: Sustainable Cities and Communities**

CleanCity is a responsive front-end mini project that lets community members submit local waste reports, categorise issues, view a dashboard, filter reports by status, and mark issues as resolved.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Submit a sample report. Data is saved in that browser's local storage.

No server or external package is required. Google Fonts are optional; the app falls back to system fonts.

## Features
- Waste reports with location, category and description
- Dashboard counts for total, open and resolved reports
- Status filtering
- Mark an open report as resolved
- Responsive layout for mobile and desktop
- Browser local-storage persistence

## Technology
HTML5, CSS3, Vanilla JavaScript, Browser Local Storage.

## Scope and limitations
This is an academic demonstration prototype. It does not send reports to a municipal authority, use GPS, authenticate users, or synchronise data between devices. A production version could add a backend database, admin roles, maps, image uploads and municipal integration.
